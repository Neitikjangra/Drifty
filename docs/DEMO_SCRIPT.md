# Drifty: 3-minute demo script

Record on https://drifty-six.vercel.app with a laptop (agency) and a phone (client).

**Before recording:** sign up fresh with "Add a demo project" ticked. Download demo v2 and v3 from
the Demo guide. Open Priya's link on the phone (Client people → Copy link again). If the AI says
it's busy, wait 30 s and press again.

| Time | Screen | Say / do |
| --- | --- | --- |
| 0:00–0:15 | A messy WhatsApp thread (screenshot) → Drifty | "Before: feedback lost in WhatsApp, five revision rounds, 'I never approved that'. After: one room that tracks it all." |
| 0:15–0:40 | Laptop: new project → invite → **Share on WhatsApp** | "The client gets a personal link on WhatsApp and opens the room on their phone, with no app." |
| 0:40–1:15 | Phone: client records a **Hinglish voice note** ("logo thoda bada karo, button pe Book now likho"). Laptop: **Summarise feedback** | "Drifty transcribes it and turns it into a clear English change list, each item quoting the client." |
| 1:15–1:40 | Phone: **conflict card** (Priya: bigger logo, Rahul: smaller) → Priya taps A | "Two client people disagree, so the approver decides, in the room." |
| 1:40–2:10 | Laptop: upload **v2** (misses the CTA) → drift card **Missing** → Back to creative → upload **v3** → all **Done** → Send | "A version that misses a change never reaches the client." |
| 2:10–2:35 | Phone: **Approve v3** → green on both screens → **Approval ledger** → Export CSV | "Exact copy, approver, time, file fingerprint: a dispute-proof record." |
| 2:35–2:50 | Dashboard: **time saved** card | "About X hours saved and N drifts caught on this project alone (estimate)." |
| 2:50–3:00 | QR code to the live URL | "Free for 2 clients. Scan and try the demo yourself." |
